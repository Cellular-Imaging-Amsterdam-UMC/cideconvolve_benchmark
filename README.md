# CIDeconvolve Benchmark

Comparative benchmark and test workflow for 2D/3D microscopy deconvolution.
It packages the current CIDeconvolve core as a Bilayers/BIOMERO-compatible
workflow and compares multiple deconvolution backends on the same input.

The workflow can run through Docker, the PyQt6 desktop launcher, or directly
from `wrapper.py`. The Bilayers interface is defined in `config.yaml`; Gradio
and Jupyter images are intentionally not part of this repository.

## Outputs

Normal mode writes deconvolved OME-TIFF results. Benchmark mode additionally
writes:

- `benchmark_metrics_<image>.csv`: one row per method and iteration count
- `benchmark_provenance_<image>.json`: environment, PSF, metadata, and CLI provenance
- `decon_benchmark_<image>.png`: optional visual comparison montage
- deconvolved OME-TIFF outputs for successful benchmark runs

Rows include timing, CPU/RAM/GPU usage, status or skip reason, tiling and crop
settings, and no-reference image metrics. Synthetic inputs generated by
`create3d_gt.py` are automatically paired with their sibling ground-truth image
for additional quality metrics.

## Metadata and PSFs

Image metadata is used where available for pixel size, numerical aperture,
refractive indices, microscope type, wavelengths, and confocal pinhole size.
With `--overrule_image_metadata true`, the supplied workflow values replace
image metadata; otherwise they only fill missing values.

The CI implementation in `deconvolve_ci.py` is synchronized with the current
upstream core, including its SNR-aware setup and optional optimized CUDA FFT
backend. The optimized CUDA source lives in `optimized_cuda/` and falls back to
the PyTorch CUDA implementation when a compatible compiled extension is not
available.

## Desktop launcher

Install the launcher dependencies and start it:

```bash
python -m pip install -r requirements_launcher.txt
python launcher.py
```

The launcher is based on the generic Bilayers launcher from `cisegmentation`.
It reads `config.yaml`, exposes beginner and advanced parameters, previews both
Docker and local commands, and provides separate **Run Docker** and
**Run Locally** buttons. Its default folders are `infolder/` and `outfolder/`.

## Docker

On Windows:

```bat
builddocker.cmd
run.cmd --benchmark true
```

Equivalent manual run:

```bash
docker run --rm --gpus all \
  -v /path/to/input:/data/in \
  -v /path/to/output:/data/out \
  w_cideconvolve_benchmark:latest \
  --infolder /data/in \
  --outfolder /data/out \
  --local \
  --benchmark true \
  --bench_iterations "20, 40, 60"
```

For one method, use `--benchmark false --method sdeconv_rl --iterations 40`.

## Local workflow

```bash
python wrapper.py \
  --infolder ./infolder \
  --outfolder ./outfolder \
  --local \
  --benchmark true \
  --bench_iterations "20, 40, 60"
```

The CLI also accepts Bilayers' JSON parameter form through `--parameters`.

## Synthetic test images

Create a deterministic blurred/noisy input and matching ground truth:

```bash
python create3d_gt.py --no-gui --output synthetic --z 64 --yx 256
```

The generated OME-TIFF metadata includes pixel size, objective information,
refractive indices, microscope mode, wavelengths, and pinhole size.

## Methods

The single-method selector contains:

- `sdeconv_rl`, `sdeconv_wiener`, `sdeconv_spitfire`
- `ci_rl`, `ci_rl_tv`, `ci_sparse_hessian`
- `pycudadecon_rl_cuda`
- `deconwolf_rl`, `deconwolf_shb`
- `deconvlab2_rl`, `deconvlab2_rltv`, `deconvlab2_landweber`, `deconvlab2_ista`
- `redlionfish_rl`
- `skimage_rl`, `skimage_unsupervised_wiener`, `skimage_cucim_rl`

See `METHODS.md` for backend and platform details. Benchmark suites are defined
in `config.yaml`; unsupported methods are recorded as skipped rather than
aborting the run.

## Main files

```text
config.yaml               Bilayers workflow interface
bilayers_cli.py            Bilayers parsing, generation, and validation helper
wrapper.py                 Workflow entrypoint and benchmark runner
deconvolve.py              Method dispatch, metadata, PSF, and output handling
deconvolve_ci.py           Current upstream CI deconvolution core
optimized_cuda/            Optional compiled CUDA FFT backend source
launcher.py                Generic PyQt6 Bilayers launcher
Dockerfile                 Headless benchmark image
requirements_docker.txt    Container dependencies
requirements_launcher.txt  Desktop launcher dependencies
vendor/                    Vendored deconvolution libraries
```
